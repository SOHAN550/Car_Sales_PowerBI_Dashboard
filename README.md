# Car_Sales_PowerBI_Dashboard 🚗 Overdrive Insights

## Project Overview
This Power BI project provides a comprehensive analysis of car sales data. The goal is to help stakeholders understand sales distribution, identify top-performing manufacturers, and track Sales growth over time.

## Key Features
* **Sales Overview:** High-level KPIs for Total Revenue, Average Price, and Cars Sold.
* **Trend Analysis:** Month-over-month sales performance.
* **Regional Insights:** Map visualization showing sales by dealer region.
* **Product Performance:** Breakdown of sales by Body Style (SUV, Sedan, Hatchback, etc.).

## Tools Used
* **Power BI Desktop:** Data modeling, DAX measures, and Visualization.
* **Power Query:** Data cleaning and transformation.
* **Excel/CSV:** Raw data source.

## Technical Highlights
* Used **DAX** for complex measures like `Year-to-Date (YTD) Sales` and `YoY Growth %`.
* Implemented **Power Query** to handle null values and format date tables.
* Designed a custom theme for a "Dark Mode" premium automotive feel.
